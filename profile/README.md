## English

> **About**
> This organization hosts the **source code, examples and lab exercises (TP)** that accompany the courses and tutoring sessions I give, referenced from **[killianreine.com](https://killianreine.com)**. Each repository maps to one course session and is meant to be **cloned, run, tested and completed** by students.

**What you'll find here**

| | |
|:--|:--|
| Course sources | Full, working code shown during a lecture or tutoring session |
| Lab exercises (TP) | Starter code + instructions, meant to be completed |
| Corrections | Reference solutions, published once a session is over |
| Languages | Mostly `C`, `Java`, `Python`, `PHP`, `JS/TS`, depending on the course |

**Naming convention**

Repositories generally follow `<subject>-<session>-sources-<year>`, e.g. [`ihm-swing-05-sources-2026`](https://github.com/killian-reine-cours/ihm-swing-05-sources-2026) — *"Sources used in IHM Swing session 5: customizing `JComponent`-based components."*

**How to use a repo**

1. Open the repo for your course/session on the [org page](https://github.com/orgs/killian-reine-cours/repositories).
2. `git clone` it (or download the ZIP) to get the sources locally.
3. Read the repo's own `README.md` for setup/run instructions — they vary by language and course.
4. For TP repos: complete the missing parts, then compare with the correction once published.

Most repositories are released under permissive open-source licenses (commonly **Apache-2.0**) so you're free to reuse them for learning.

## Français

> **À propos**
> Cette organisation regroupe les **codes sources, exemples et travaux pratiques (TP)** liés aux cours et séances de tutorat que je donne, référencés depuis **[killianreine.com](https://killianreine.com)**. Chaque dépôt correspond à une séance de cours et est fait pour être **cloné, testé et complété** par les étudiants.

**Ce que vous trouverez ici**

| | |
|:--|:--|
| Sources de cours | Code complet et fonctionnel présenté en cours ou en tutorat |
| TP | Code de départ + consignes, à compléter |
| Corrections | Solutions de référence, publiées une fois la séance terminée |
| Langages | Principalement `C`, `Java`, `Python`, `PHP`, `JS/TS`, selon le cours |

**Convention de nommage**

Les dépôts suivent en général `<matière>-<séance>-sources-<année>`, par ex. [`ihm-swing-05-sources-2026`](https://github.com/killian-reine-cours/ihm-swing-05-sources-2026) — *« Codes sources utilisés dans le cours 5 d'IHM SWING : personnalisation des composants basés sur `JComponent`. »*

**Comment utiliser un dépôt**

1. Ouvrez le dépôt de votre cours/séance depuis la [page de l'organisation](https://github.com/orgs/killian-reine-cours/repositories).
2. Faites un `git clone` (ou téléchargez le ZIP) pour récupérer les sources en local.
3. Lisez le `README.md` du dépôt pour les instructions d'installation/exécution — elles varient selon le langage et le cours.
4. Pour les TP : complétez les parties manquantes, puis comparez avec la correction une fois publiée.

La plupart des dépôts sont publiés sous des licences open source permissives (souvent **Apache-2.0**), libres de réutilisation pour l'apprentissage.
